INSTALL THE PREVIEW

  1. Download BridgeConsoleTV.apk to your Android TV, or transfer it from your computer or phone.
  2. Open the APK with a browser or file manager. If Android asks, allow that application to install unknown apps, then install Bridge Console TV.
  3. Open Bridge Console TV from your apps list and try remote navigation, themes and settings.
  4. Default-launcher setup varies by TV. Confirm the app works on your device before changing your default Home app. onn setup instructions.

Home Assistant and notification access are optional and configured separately inside the app.

Moving from a development build? This public APK uses a dedicated release signing key. Development-signed installs cannot update directly to it. Export your launcher settings before switching; uninstalling can remove app data.

USE AS HOME ON YOUR ONN BOX

  1. Open Bridge Console TV → Settings → Android & device → Choose default home app. Select Bridge Console TV if Android offers the chooser.
  2. If that option is unavailable, use ADB on your own box to save the current Home component, set Bridge as Home, then verify the result and test your remote.
adb -s TV_ADDRESS shell cmd package set-home-activity --user 0 lab.jackson.lcars/.MainActivity

Replace TV_ADDRESS with your own box's entry from adb devices. Keep the original launcher installed. The complete guide includes connection setup, saving the previous Home setting, verification, undo and a tvQuickActions Home-button alternative.

Read the full onn setup guide

Menu names and Home behavior vary by firmware. Remapping Home with another app is a workaround; it does not by itself change Android's registered default launcher.
